# MY-UJLOG-CI
My UJLoG est une plateforme numérique dédiée à la communauté universitaire de l’Université Jean Lorougnon Guédé (UJLoG). Elle rassemble des services étudiants, une messagerie, un espace communautaire et une Marketplace permettant aux partenaires de développer leurs activités.  Une application conçue et développée par SIAMS — © 2026.
